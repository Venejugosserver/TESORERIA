# Logos

Un archivo PNG por proveedor, banco o empresa. El nombre es el del Excel en minúsculas, sin acentos y con guiones:

| En el Excel | Archivo |
|---|---|
| `PEPSICO` | `pepsico.png` |
| `ALIMENTOS POLAR` | `alimentos-polar.png` |
| `LOGISTICA N$A` | `logistica-n-a.png` |
| `BANESCO` | `banesco.png` |

Lo más cómodo es subirlos desde el panel administrativo (sección Logos): muestra el nombre exacto de cada uno, ajusta la imagen y la publica aquí.
Si un logo no existe, el tablero muestra las iniciales.
